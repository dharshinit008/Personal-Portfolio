# Personal Portfolio Website

## About

A full-stack personal portfolio website built to showcase my skills, projects, and contact information.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Features

- Personal introduction
- Skills section
- Projects showcase
- Dynamic project data from MongoDB
- Contact form
- Backend API integration

## Project Structure

- `frontend/` - Frontend files
- `backend/` - Backend server and database integration
